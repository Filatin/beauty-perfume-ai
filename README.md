# 💄 Beauty & Perfume Copywriter AI Telegram Bot

An intelligent e-commerce copywriting assistant built for the **Beauty & Perfumes** industry. The bot generates conversion-focused Instagram posts, marketplace descriptions (Allegro / Amazon), and perfume dupe analyses using **Google Gemini 2.5 Flash** and **Aiogram 3**.

---

## 🚀 Features

- **Multi-language Support:** Polish (PL) and English (EN) workflows.
- **E-Commerce Copy Generation:**
  - 📦 **Allegro / Amazon SEO Descriptions:** Structured product titles, notes, and audience targeting.
  - 📱 **Instagram Posts:** Engaging hooks, sensory copywriting, and relevant hashtags.
  - 🔍 **Dupe Finder & Analysis:** Fragrance breakdown and budget-friendly alternatives.
- **Asynchronous Architecture:** Built on `aiogram 3.x` for high-throughput messaging.

---

## 🛠 Tech Stack

- **Language:** Python 3.10+
- **Telegram Bot Framework:** [Aiogram 3](https://docs.aiogram.dev/)
- **LLM Engine:** [Google Gemini API (`gemini-2.5-flash`)](https://ai.google.dev/)
- **Configuration:** `python-dotenv`
